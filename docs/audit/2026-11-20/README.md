# 냉정한 평가 (2026-11-20)

지금 상태(시험용 층, 집, 출근길)를 독립 평가자 넷이 채점하고, 반박 검증자 하나가 지적을 다시 확인해 걸러 냈다. 평가자에게는 만든 쪽의 결론을 주지 않고 화면·코드·설계 문서만 줬다. 평가자와 검증자는 모두 AI 다.

## 결과: 100점 중 약 35점

| 영역 | 배점 | 점수 | 근거 |
|---|---|---|---|
| 미감: 3D 티 | 10 | 1.7 | 집 1/3, 출근길 0/3 |
| 미감: 정지 화면 | 15 | 5.3 | 여덟 항목, 집 9/24 · 출근길 8/24 |
| 미감: 움직임 | 15 | 6.7 | 여섯 항목 8/18 (연출은 검증에서 1 → 2) |
| 조작감 | 30 | 10.0 | 여덟 항목 8/24 ('동작의 묶임' 0점) |
| 재미·진척·기술 | 30 | 11.7 | 여섯 항목 7/18 (독창성·권리는 검증에서 1 → 2) |

- 항목 점수는 0~3 (0 = 심각, 1 = 눈에 띄게 모자람, 2 = 무난하지만 목표에 못 미침, 3 = 목표 수준).
- 시험용 층의 화면 미감 점수(27점 만점에 4)는 합계에서 뺐다. 스스로 '시험용'이라 밝힌 방에 출시 기준을 댄 것이라는 검증자 판정을 따랐다.
- 검증: 지적 44건 가운데 확인 17, 부분(사실이지만 과장) 25, 기각 1, 확인 불가 1.
- 사용자가 가장 무겁게 보는 것은 조작감과 미감이다. 사용자 의견: "너무 3d3d라서 어색한 감이 약간 있다."

## 살아남은 무거운 지적

**미감**
- 출근길 도시가 회색 상자 그대로다. 같은 파란 창이 격자로 반복되고 건물 재질 자체가 회색이다.
- 집 바깥은 삼각면이 드러난 돔인데 안은 돌 블록 이글루라 다른 물체로 보인다. 안쪽 방(반지름 4m)이 바깥(3m)보다 크다.
- 설계 문서의 아트 방향이 '로우폴리 + 단색 면 + 약한 명암'이다. 기대 수준으로 잡은 회화풍과 반대 방향이다.
- 남색 Ram 이 집의 그늘과 바닥에 묻혀 흰 돌머리만 보인다.
- 등 뒤 카메라에서는 피니시가 맞는 순간 돌머리가 몸에 가려진다.
- 박치기 6종인데 실루엣은 3종으로 겹친다.

**조작감**
- 동작 중 누른 입력이 전부 버려진다. 헛친 박치기에 0.9~1.4초 묶이고 끊을 방법은 Space 콤보뿐이다.
- Space 를 누르면 4종 가운데 무작위로 나가, 맞는 시점이 최대 0.17초, 전진 거리가 0.26~0.82m 로 달라진다.
- 대시가 달리기보다 빠르지 않고(0.61초에 1.05m), 누르는 순간 0.13초 멈칫한다.
- 같은 키가 시험용 층(돌기 + 앞뒤)과 집·출근길(자유 이동)에서 다른 동작을 한다.
- 집 안 방 가장자리에서 방향키와 화면상 이동 방향이 최대 58° 어긋난다(절반 넘게는 화면 가장자리 원근 탓).
- 디딘 발의 미끄러짐이 평가자 측정으로 23~25% 남아 있다(2026-11-20 에 느낌 피드백으로 고른 속도의 결과. 사람 눈으로 다시 볼 것).

**재미·진척·기술**
- 적이 하나도 없다. 박치기 대상은 시험용 층의 상자뿐이고, 집과 출근길에는 맞을 것이 없다.
- 패링·막기·락온은 판정이 없는데 화면과 README 는 'E 패링'이라고 부른다.
- 출근길은 플레이어가 하는 일이 10초 달리기뿐이다.
- 걸을 수 있는 곳을 물리 벽이 아니라 좌표 되돌리기로 지키고, 그 좌표(직원 자리, 방 벽, 광장 길이)가 Blender 스크립트와 게임 코드에 따로 적혀 있다.
- 자동 점검이 내부 변수에 기대고, '화면에 보인다'를 가림 없이 시야각으로만 본다.
- 버그: 산재비스탄을 쓰면 출근길 카메라가 느려진 시간으로 따라와 끈적해진다.

## 검증에서 걸러지거나 줄어든 것

- 기각: "박치기가 멈춘 뒤에 맞는다" — 게임이 쓰지 않는 첫 판 동작(`Attack_Slam`)을 보고 한 말이었다.
- 과장: "9일치 미커밋"은 이틀치, "정문에서 Ram 이 거의 안 보인다"는 원본 화면에서 약 28px 로 보인다.
- 원인 틀림: 출근길이 회색인 것은 안개 탓이 아니라 건물 재질 탓이다.
- 캡처 방식 탓: 가까이 찍은 컷(`close_*`)은 게임 카메라가 아니고, 위에서 본 컷은 게임에 없는 각도다.

## 사용자가 이미 정한 것과 부딪히는 지적

평가자는 깎았지만 승인된 선택이다. 결함으로 볼지는 사용자가 정한다.
- 정문 줌 아웃에서 Ram 이 화면 높이의 약 4% 로 작아지는 것.
- Ram 의 찡그린 눈매.

## 판정하지 못한 것

손맛, 소리, 속도감, 히트스톱과 화면 흔들림의 체감, 실제 화면 표시 지연, 성능, 상표 등록 상태.

## PC 세션이 할 일

1. **Godot 세팅**: `tools/setup_windows.ps1` 을 실행한다 (Git 없으면 설치 → 바탕화면\Godot 에 Godot 4.7.2 → 바탕화면\home\ram 저장소 pull → 에디터 열기). 에디터가 뜨면 F5 로 실행해 사용자가 조작감을 확인한다.
2. **예전 프로젝트 분석**: 사용자가 예전에 하데스를 분석해서 만든 게임 프로젝트(집 PC 바탕화면의 `home` 폴더)를 GitHub 에 올리면 바탕화면\home 아래에 받는다. Ram 에 가져다 쓸 만한 것(방 진행·보상 선택·영구 성장·저장 구조, 코드 구조, 전투 시스템 등)을 분석해 정리한다. **사용자가 정하기 전에는 아무것도 옮기거나 고치지 않는다.**
3. 사용자 피드백(회전 속도, 카메라 지연, 박치기 타격감 등)을 받아 `game/` 을 다듬고, 바꾸면 스모크 테스트를 다시 돌린다.

## 일하는 방식 (사용자와 맞춘 것)

- 한국어로 답한다. 정확도를 가장 중요하게 여긴다.
- 게임 프로젝트는 바탕화면\home 에 모은다. Ram 저장소는 바탕화면\home\ram, Godot 는 바탕화면\Godot.
- 디자인을 바꿀 때는 전·후를 나란히 보여 주고 고른 것만 반영한다.
- 작업한 것은 `main` 에 커밋·푸시한다 (개인 저장소, 사용자가 main 에 바로 올리기로 함). 커밋 작성자 이메일은 ace70401@gmail.com.
- 설계 결정이 생기면 `docs/design.md` 와 원본 설계 문서(https://claude.ai/artifact/84osqWgQkDQugsrKgKLPxC) 둘 다에 적는다.
- 다른 게임의 고유 이름·디자인(두개도스·램펄드, 사이버펑크 2077 용어 등)을 그대로 쓰지 않는다. 산재비스탄은 출시 전 상표 검토가 필요하다.

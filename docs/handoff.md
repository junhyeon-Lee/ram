## 일하는 방식 (사용자와 맞춘 것)

- 한국어로 답한다. 정확도를 가장 중요하게 여긴다.
- 게임 프로젝트는 바탕화면\home 에 모은다. Ram 저장소는 바탕화면\home\ram, Godot 는 바탕화면\Godot.
- 디자인을 바꿀 때는 전·후를 나란히 보여 주고 고른 것만 반영한다.
- 동작을 만들거나 고칠 때는 `.claude/skills/ram-motion` 스킬 순서를 따른다(수치 고치기 → 다시 만들기 → GIF·프레임 시트 확인 → 게임 연결·스모크 테스트).
- 회사 PC 에서 모델·동작을 다시 만들 때 쓰는 bpy 가상환경은 바탕화면\home\ram-explorations\.venv (Python 3.13, bpy 5.3, Pillow). 시안도 그 폴더에서 만든다.
- 작업한 것은 `main` 에 커밋·푸시한다 (개인 저장소, 사용자가 main 에 바로 올리기로 함). 커밋 작성자 이메일은 ace70401@gmail.com.
- 설계 결정이 생기면 `docs/design.md` 와 원본 설계 문서(https://claude.ai/artifact/84osqWgQkDQugsrKgKLPxC) 둘 다에 적는다.
- 다른 게임의 고유 이름·디자인(두개도스·램펄드, 사이버펑크 2077 용어 등)을 그대로 쓰지 않는다. 산재비스탄은 출시 전 상표 검토가 필요하다.
